# A/B-тест рекламного креатива

## О проекте

Это учебный pet-проект по проведению и анализу A/B-теста на Python. Цель — оценить, отличается ли поведение наблюдений, которым был показан новый рекламный креатив, от контрольной группы.

Проект включает проверку распределения экспериментальных групп (SRM), расчёт долей ответов, разницы между долями, 95%-го доверительного интервала, p-value и приближённого минимального обнаруживаемого эффекта (MDE), а также визуализацию результатов.

## Бизнес-вопрос и метрика

**Основной вопрос:** отличается ли доля ответов `Yes` среди наблюдений, которые дали ответ, между контрольной группой и группой нового креатива?

- `control` — контрольная группа;
- `exposed` — группа, которой был показан новый креатив.

Основная метрика:


p = Yes / (Yes + No)

Она показывает долю `Yes` **среди ответивших**. Строки, в которых `yes = 0` и `no = 0`, не входят в знаменатель этой метрики.

Гипотезы:

- **H₀:** \(p_{control} = p_{exposed}\) — доли `Yes` среди ответивших равны;
- **H₁:** \(p_{control} \ne p_{exposed}\) — доли различаются.

Используется двусторонняя проверка с уровнем значимости \(\alpha = 0.05\).

## Данные

Исходный файл: `ad_smart_data.csv`.

В датасете **8 077 строк и 9 столбцов**. Идентификатор `auction_id` уникален для каждой строки; пропусков в столбцах нет. Данные охватывают период с 3 по 10 июля 2020 года.

Основные поля:

| Поле | Описание |
|---|---|
| `auction_id` | Идентификатор записи аукциона |
| `experiment` | Экспериментальная группа: `control` или `exposed` |
| `date`, `hour` | Дата и час |
| `device_make`, `platform_os`, `browser` | Информация об устройстве, ОС и браузере |
| `yes` | Индикатор ответа `Yes` (0 или 1) |
| `no` | Индикатор ответа `No` (0 или 1) |

Поля `yes` и `no` не принимают значение 1 одновременно. Если оба равны 0, в записи нет зафиксированного ответа. В датасете 572 ответа `Yes`, 671 ответ `No` и 6 834 записи без ответа. Таким образом, всего зафиксировано 1 243 ответа, а не 1 243 наблюдения во всём эксперименте.

## Использованные методы

### 1. Проверка распределения групп — SRM

SRM (Sample Ratio Mismatch) проверяет, насколько фактическое соотношение групп отклоняется от ожидаемого. В проекте ожидается распределение 50/50. Применяется критерий хи-квадрат согласия (`scipy.stats.chisquare`) с порогом `SRM_ALPHA = 0.001`.

Отсутствие статистически значимого SRM не доказывает, что эксперимент полностью корректен: отдельно могут требовать проверки сбор событий, фильтрация данных и другие аспекты дизайна эксперимента.

### 2. Разница долей и доверительный интервал

Рассчитываются доли `Yes` среди ответивших в обеих группах и разница:

\[
\Delta = p_{exposed} - p_{control}
\]

95%-й доверительный интервал для разницы долей рассчитывается нормальным приближением с оценкой стандартной ошибки по раздельным дисперсиям групп. Это приближённый Wald-интервал.

### 3. Проверка гипотезы

Для таблицы сопряжённости `Yes` / `No` по группам используется `scipy.stats.chi2_contingency`. Для таблицы 2×2 функция SciPy по умолчанию применяет поправку Йейтса на непрерывность.

### 4. MDE

MDE (Minimum Detectable Effect) оценивает минимальный размер эффекта, который планируемый тест способен обнаруживать с заданной статистической мощностью. В проекте используется приближённый расчёт при двустороннем уровне значимости 5% и мощности 80%:

\[
MDE \approx (z_{1-\alpha/2} + z_{1-\beta})
\sqrt{p_{pool}(1-p_{pool})\left(\frac{1}{n_c}+\frac{1}{n_e}\right)}
\]

где \(p_{pool}\) — объединённая доля `Yes` среди ответивших, а \(n_c\) и \(n_e\) — количество ответивших в контрольной и экспериментальной группах. MDE не является жёсткой границей: эффект меньше MDE тоже может оказаться статистически значимым, но вероятность его обнаружения ниже целевой мощности.

### 5. Визуализация

В `visualisation.ipynb` строятся столбчатые диаграммы долей `Yes` по группам и графики с 95%-ми доверительными интервалами для долей каждой группы.

## Результаты основного анализа

### Проверка SRM

| Показатель | Значение |
|---|---:|
| Ожидаемое распределение | 50% / 50% |
| Фактические размеры групп | 4 071 / 4 006 |
| Фактическое распределение | 50,40% / 49,60% |
| Статистика \(\chi^2\) | 0,5231 |
| p-value | 0,4695 |
| Порог SRM | 0,001 |

Так как `p-value > 0.001`, статистически значимого расхождения с ожидаемым распределением 50/50 не обнаружено. Это не является доказательством отсутствия любых проблем с экспериментом, но данная проверка не выявила SRM.

### Основная метрика: доля `Yes` среди ответивших

| Показатель | Control | Exposed |
|---|---:|---:|
| Ответивших | 586 | 657 |
| Ответов `Yes` | 264 | 308 |
| Доля `Yes` | 45,05% | 46,88% |

Разница долей (`exposed − control`) составляет **+1,83 процентного пункта**.

| Статистический показатель | Значение |
|---|---:|
| Объединённая доля `Yes` (`p_pool`) | 0,4602 |
| 95%-й доверительный интервал разницы | от −3,72 до +7,38 п. п. |
| p-value (хи-квадрат, с поправкой Йейтса) | 0,5561 |
| Приближённый MDE при \(\alpha=0.05\) и power = 80% | 7,93 п. п. |

**Интерпретация:** p-value больше 0,05, а доверительный интервал включает ноль. Поэтому нет оснований отвергать нулевую гипотезу: по этим данным статистически значимое различие долей `Yes` среди ответивших не обнаружено. Это не доказывает, что эффект равен нулю. Интервал допускает как снижение, так и рост доли `Yes`.

При текущем количестве ответивших MDE составляет примерно 7,9 п. п. Наблюдаемая разница (+1,83 п. п.) существенно меньше этого значения. Для обнаружения эффекта около 2 п. п. при сопоставимых предположениях и мощности 80% ориентировочно потребуется около **9,7–10 тыс. ответивших в каждой группе**. Это приближённая оценка размера выборки; при планировании нового эксперимента расчёт следует выполнить отдельно с заранее заданным эффектом, уровнем значимости, мощностью и ожидаемой долей ответивших.

## Дополнительная проверка: доля ответивших

Поскольку основная метрика рассчитана только среди ответивших, важно также посмотреть, как часто записи вообще содержат ответ. По исходному CSV получены следующие показатели:

| Показатель | Control | Exposed |
|---|---:|---:|
| Доля ответивших среди всех записей группы | 14,39% | 16,40% |

Разница составляет **+2,01 п. п.** в группе `exposed`; 95%-й приближённый доверительный интервал — от +0,43 до +3,58 п. п. При проверке таблицы «ответил / не ответил» критерием хи-квадрат с поправкой Йейтса получено `p-value ≈ 0.0136`.

Это дополнительное наблюдение важно для интерпретации основного анализа: доля ответивших между группами различается, а условная доля `Yes` считается только среди тех, кто ответил. Если сам креатив влияет на вероятность ответа, сравнение только ответивших может не отражать полный эффект эксперимента. Этот дополнительный расчёт пока не выводится автоматически скриптом `main.py`; его стоит добавить в код, чтобы все результаты воспроизводились одним запуском.

В качестве исследовательской метрики можно также рассмотреть долю `Yes` среди всех записей группы (`yes / число всех записей`). Она составляет 6,48% в `control` и 7,69% в `exposed` (разница +1,20 п. п.; хи-квадрат с поправкой Йейтса: `p-value ≈ 0.0389`). Такая метрика учитывает отсутствие ответа как отсутствие зафиксированного положительного ответа, поэтому отвечает на другой вопрос, чем основная метрика. Этот результат следует считать дополнительным/исследовательским, а не подменять им основную гипотезу постфактум; выбор основной метрики нужно фиксировать до анализа.

## Вывод

В проверке SRM статистически значимого расхождения между размерами групп не обнаружено. По основной метрике — доле `Yes` среди ответивших — статистически значимого различия между креативами также не обнаружено (`p-value = 0.5561`, 95%-й ДИ включает ноль). При этом доверительный интервал достаточно широк, а расчётный MDE высок относительно наблюдаемого эффекта, поэтому тест не позволяет уверенно исключить небольшое изменение метрики.

Дополнительно в экспериментальной группе выше доля записей с ответом. Это может быть содержательным результатом, но требует явного определения основной метрики и дальнейшей проверки. Практический следующий шаг — добавить анализ response rate в основной скрипт и при необходимости спланировать новый эксперимент, рассчитав необходимый размер выборки до его запуска.

Запускайте команды из каталога проекта.

   ```bash
   python -m pip install pandas scipy matplotlib notebook
   ```

   ```bash

   ```

   ```bash
   jupyter notebook visualisation.ipynb
   ```
