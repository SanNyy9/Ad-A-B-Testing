О проекте

Это мой первый проект по проведению и анализу A/B-теста. 
Цель — проверить, влияет ли новый рекламный креатив на поведение пользователей. 
Проект охватывает полный цикл анализа: 
от постановки бизнес-вопроса до интерпретации результатов и выводов для принятия продуктового решения.

В будущем планируется расширить проект и ответить ещё на несколько бизнес-вопросов.


Бизнес-вопрос

Влияет ли креатив на долю ответов «Yes» среди ответивших?
Группа control — пользователи, увидевшие исходный креатив;
Группа exposed — пользователи, увидевшие новый креатив.


Метрика

p = yes / (yes + no)
 
Доля ответивших «Yes» среди тех, кто вообще дал ответ. 
Метрика выбрана как прокси-индикатор вовлечённости и заинтересованности аудитории креативом.


Гипотезы

H0: p_control = p_exposed — креатив не меняет долю «Yes».
H1: p_control != p_exposed — креатив меняет долю «Yes».
Двусторонняя проверка, уровень значимости a = 0.05.


Данные
Файл: ad_smart_data.csv

Ключевые поля:
experiment — группа (control / exposed);
yes / no — ответы пользователей.
Разбиение по группам — из экспериментального дизайна (рандомизация на этапе показа).


Использованные инструменты и методы

1. Расчёт точечных оценок и разницы долей

proportion_yes_control, proportion_yes_exposed — доли «Yes» в каждой группе;
delta = p_exposed − p_control — точечная оценка эффекта.
2. Пул-оценка и MDE (Minimum Detectable Effect)

p_pool — объединённая доля «Yes» по обеим группам;
MDE = (z_a + z_b) · (p_pool·(1−p_pool)·(1/n_c + 1/n_e))**0.5 — минимальный эффект, который тест способен обнаружить при power = 80%.
3. Доверительный интервал для разницы долей

Оценка стандартной ошибки разницы через раздельные дисперсии;
95% CI = delta +- z_a · SE.
4. Проверка гипотезы — хи-квадрат Пирсона

Таблица сопряжённости Yes × No по группам;
scipy.stats.chi2_contingency = chi2, p-value, dof, expected.
5. Визуализация (matplotlib)

Барчарт долей «Yes» с подписями значений;
Барчарт долей «Yes» с 95% доверительными интервалами (error bars).

Выводы

1. 95% доверительный интервал для разницы долей «Yes» (exposed − control) составил [−0.037; 0.074].
Интервал содержит 0, поэтому нет оснований отвергнуть H₀. Точечная оценка близка к нулю, 
но ширина интервала допускает как небольшое снижение, так и небольшой рост доли «Yes».

2. p-value = 0.5561 > α = 0.05 — не отвергаем H₀. Если бы эффекта не было,
вероятность увидеть наблюдаемую разницу или более экстремальную составила бы 55.6%. 
Наблюдаемая разница хорошо объясняется случайным разбросом.

3. MDE = 7.9 п.п. — при текущем размере выборки тест надёжно обнаруживает только эффект от ~8 п.п.
Наблюдаемая точечная оценка (+1.8 п.п.) в 4.4 раза меньше MDE. 
Если реальный эффект и есть, но меньше 8 п.п., тест мог его не заметить. 

Для детектирования эффекта в 2 п.п. понадобится примерно в 16 раз больше данных (~10 000 ответивших в каждой группе).
Продуктовый вывод: по текущим данным креатив не даёт статистически значимого изменения доли «Yes». Решение — либо увеличивать выборку, либо фиксировать результат как «эффекта не обнаружено».
